# 阿里雲 OSS 資源上傳

在筆記裡插入圖片、影音或附件時，自動上傳到阿里雲 OSS，內文裡留下一個可以直接開啟的連結。發佈到部落格或分享給別人時，圖片也能正常顯示。

## 開始使用

1. 在外掛中心安裝「阿里雲 OSS 資源上傳」，再到外掛頁的「已安裝」裡開啟開關。
2. 開啟外掛詳情的「設定」。
3. 填寫「AccessKey ID」、「AccessKey Secret」、「Bucket」和「區域」（例如 `oss-cn-hangzhou`），金鑰需要寫入權限，儲存貯體要提前建好。「目錄」可留空。
4. 儲存設定後，前往「設定 → 資源儲存」選用此服務，再在筆記裡插入一張圖片試試：內文裡能看到，在瀏覽器裡開啟連結也能看到，就說明設定好了。

想用自己的網域或 CDN，就在「公開網址前綴」裡填上，產生的連結會使用這個前綴。圖片是否壓縮，跟隨 Tau 的「上傳壓縮」開關。

## 常見問題

**上傳失敗？** 檢查帳號、儲存貯體和網路。上傳失敗時不會偷偷改存到別的地方。

**上傳成功了，但連結打不開？** 通常是儲存貯體沒有開放公開讀取，或者自訂網域沒設定好。外掛不會幫你改儲存貯體的存取權限，需要你到阿里雲控制台設定。

**在單獨開啟的視窗裡插圖片沒反應？** 請保持 Tau 主視窗開著，並確認外掛已經啟用。

**能同步我的筆記嗎？** 不能。這個外掛只負責上傳附件，同步資料庫請用同步外掛。

## 小提醒

- 支援電腦與手機；如果同時安裝了同步外掛，兩邊的帳號分開填寫，互不影響。
- AccessKey 等同於帳號的鑰匙，不要發給別人，也不要貼在截圖或問題描述裡。
