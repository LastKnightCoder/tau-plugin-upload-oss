# 阿里云 OSS 资源上传

在笔记里插入图片、音视频或附件时，自动上传到阿里云 OSS，正文里留下一个可以直接打开的链接。发布到博客或分享给别人时，图片也能正常显示。

## 开始使用

1. 在插件中心安装「阿里云 OSS 资源上传」，再到插件页的「已安装」里打开开关。
2. 打开插件详情的「设置」。
3. 填写「AccessKey ID」、「AccessKey Secret」、「Bucket」和「区域」（比如 `oss-cn-hangzhou`），密钥需要有写入权限，存储桶要提前建好。「目录」可留空。
4. 保存配置后，到「设置 → 资源存储」选用此服务，再在笔记里插入一张图片试试：正文里能看到，在浏览器里打开链接也能看到，就说明配置好了。

想用自己的域名或 CDN，就在「公开地址前缀」里填上，生成的链接会使用这个前缀。图片是否压缩，跟随 Tau 的「上传压缩」开关。

## 常见问题

**上传失败？** 检查账号、存储桶和网络。上传失败时不会偷偷改存到别的地方。

**上传成功了，但链接打不开？** 通常是存储桶没有开放公开读取，或者自定义域名没配好。插件不会帮你改存储桶的访问权限，需要你到阿里云控制台设置。

**在单独打开的窗口里插图片没反应？** 请保持 Tau 主窗口开着，并确认插件已经启用。

**能同步我的笔记吗？** 不能。这个插件只负责上传附件，同步资料库请用同步插件。

## 小提醒

- 支持电脑与手机；如果同时装了同步插件，两边的账号分开填写，互不影响。
- AccessKey 相当于账号的钥匙，不要发给别人，也不要贴在截图或问题描述里。
